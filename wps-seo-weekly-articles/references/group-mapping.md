## 资源池数据速查（articles_data.json）

- 入口：资源池根地址 + `articles_data.json`（默认脚本已封装，见 `scripts/fetch_pool.py`）
- 字段：`id / title / pool / cmsTab / priority / sourceType / sourceUrl / targetKeywords / notes / sourceDate / collectedDate`
- `pool`（内容池）：`AI教程` / `功能教程` / `竞品对比` / `办公选型`
- `cmsTab`：`WPS AI` / `Excel` / `PPT` / `WPS教程` / `Word` / `PDF` / `在线文档` / `office`
- `priority`：`P0`（优先）> `P1` > `P2`
- `sourceType`（来源）：`WPS 社区` / `WPS 官方公众号` / `WPS 学堂` / `WPS 客服中心` / `小绿书素材`
- 同一关键词可命中多条素材：优先取 P0、分高、近期（sourceDate）的素材作为主要参考

## 素材可用性说明

- **覆盖好的组**：教程操作、功能认知、AI认知、故障解决、格式转换（资源池中功能教程/AI教程/客服中心素材充足）
- **覆盖弱、靠网络搜索的组**：下载安装、品牌直达、模板获取、价格购买（资源池无直接字段对应，需用关键词全文匹配 + 网络搜索官方页补充）

## 组别关键词从何而来

- 自动：`scripts/pick_keywords.py` 从《WPS_SEO完整关键词库》按 10 组别 + 指定指标挑词，跨周去重
- 手动：复用 `wps-seo-weekly-keywords` 技能的周规划输出，或用 `--keywords` 直接指定
