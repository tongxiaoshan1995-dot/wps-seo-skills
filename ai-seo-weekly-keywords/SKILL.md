# AI SEO 每日关键词规划 v3

## 概述

一键输出"今天该写哪些 AI 方向关键词"的规划表：按**分层推荐**（核心 3 / 长尾 12 / 支撑 15）每日挑取 30 词（可用 `--total` 调整），核心层吃排名、长尾层吃细分长尾、支撑层铺量+内链承接。关键词按**四维指纹**去重，保证：
- **当天 30 词指纹全唯一**（一级分类×意图×对象×工具）
- **跨日不重复**（已用指纹持久化，全站同指纹只出现一次）
- **周一至周五题材/意图差异化**（题材轮转，不扎堆）
- **聚焦 AI 方向**：题材覆盖 AI写作/绘图/对话/视频/音频/编程/办公/搜索/大模型/认知 10 类
- **业务维度分类**：一级分类 = AI品牌词 / AI场景词 / AI竞品词 / AI认知词（对齐参考技能 wps-seo-weekly-keywords 的业务分类思路）
- **意图清洗为 6 类互不重复**：品牌认知 / 官网下载 / 教程操作 / 功能对比 / 模板获取 / 场景应用，每词只归一类
- **已剔除价格/会员词**（价格/免费/会员/收费/多少钱等不产出）

## 分类体系

每个词带两套分类标签：

| 维度 | 取值 | 说明 |
|------|------|------|
| **一级分类（业务维度）** | AI品牌词 / AI场景词 / AI竞品词 / AI认知词 | 品牌词=仅 WPS AI/WPS灵犀；场景词=用AI做具体事（写周报/做PPT/生成头像）；竞品词=其它AI工具品牌+对比选型/评测；认知词=概念认知（人工智能是什么/大模型前景/AIGC原理） |
| **题材（AI能力维度）** | AI写作/AI绘图/AI对话/AI视频/AI音频/AI编程/AI办公/AI搜索/大模型/AI认知 | 供周一至周五题材轮转排期 |

示例：
- `豆包写周报` → 一级分类=AI竞品词，题材=AI写作，意图=场景应用，对象=写周报，工具=豆包（含品牌→竞品词）
- `DeepSeek哪个好` → 一级分类=AI竞品词，题材=大模型，意图=功能对比，对象=哪个好，工具=DeepSeek
- `WPS灵犀写周报` → 一级分类=AI品牌词，题材=AI写作，意图=场景应用，对象=写周报，工具=WPS灵犀
- `即梦官网` → 一级分类=AI竞品词，题材=AI绘图，意图=官网下载，对象=官网，工具=即梦
- `WPS灵犀是什么` → 一级分类=AI品牌词，题材=AI认知，意图=品牌认知，对象=是什么，工具=WPS灵犀
- `AI写周报模板` → 一级分类=AI场景词，题材=AI写作，意图=模板获取，对象=写周报，工具=AI
- `大模型前景` → 一级分类=AI认知词，题材=大模型，意图=品牌认知，对象=前景，工具=大模型

## 周一至周五差异化排期

| 日期 | 主打题材 | 主攻意图 | 定位 |
|------|---------|---------|------|
| 周一 | AI写作 + AI对话 | 教程操作 + 品牌认知 | AI文字创作：写作+对话，教程为主 |
| 周二 | AI绘图 + AI视频 | 模板获取 + 教程操作 | 视觉内容：绘图+视频，模板与制作 |
| 周三 | AI编程 + AI办公 | 教程操作 + 场景应用 | 效率提升：编程+办公，落地应用 |
| 周四 | 大模型 + AI搜索 | 功能对比 + 品牌认知 | 选型决策：大模型+搜索，对比认知 |
| 周五 | AI音频 + AI认知 | 教程操作 + 品牌认知 | 泛AI收口：音频+认知，入门前瞻 |

第 6 天自动回到周一（周一~周五循环）。排期严格对齐真实日期：周末沿用周五排期。

## 分层推荐（每天 30 篇）

| 层 | 篇数 | 定位 | 选词逻辑 |
|----|------|------|---------|
| 核心 | 3 | 深度写、吃排名、配图 | 主打题材×主攻意图的高分指纹；若不足则按 品牌/场景/竞品/认知 四类分散补足 |
| 长尾 | 12 | 吃细分长尾 | 指纹去重 + 题材分散 |
| 支撑 | 15 | 铺量 + 内链承接 | 指纹去重 + 题材分散（补充铺量） |

## 四维指纹去重

每个词打 4 个标签：**一级分类 × 意图 × 对象 × 工具**，组成唯一指纹。意图为 6 类之一（品牌认知/官网下载/教程操作/功能对比/模板获取/场景应用），每词只归一类。例如：
- `AI竞品词·场景应用·写周报·豆包`（豆包写周报，含品牌）
- `AI场景词·场景应用·生成头像·Midjourney`（Midjourney生成头像）
- `AI竞品词·功能对比·哪个好·DeepSeek`（DeepSeek哪个好）
- `AI竞品词·官网下载·官网·即梦`（即梦官网）
- `AI品牌词·场景应用·写周报·WPS灵犀`（WPS灵犀写周报）
- `AI场景词·模板获取·写周报·AI`（AI写周报模板）
- `AI认知词·品牌认知·前景·大模型`（大模型前景）

同一指纹全站只推荐 1 次（状态文件 `.ai_seo_state.json` 按指纹持久化，跨日去重）。

## 内容策略标签

每词带一个内容策略标签，供写文章技能选写作模板：
- **高关联(整篇AI)**：品牌/官网/下载词，整篇围绕该 AI 工具
- **中关联(AI+工具章节)**：教程/模板/对比/场景词，先讲 AI 通用方法再带出具体工具
- **低关联(方法论轻带)**：纯方法论/认知词，末尾轻带 AI 工具

## 数据源

- 增强词库 `assets/data/ai_enhanced_kw.csv`（1284 词，已清洗分类：题材/一级分类/意图/操作对象/工具/指纹/内容策略/题材分/搜索热度/热度分，意图=6类互不重复，已剔除价格/会员词）
- 原始词库 `assets/data/ai_final_kw.csv`（1425 词，含搜索热度档位+热度分，一级分类=品牌/场景/竞品/认知四类，品牌词243 / 竞品540 / 场景451 / 认知147）
- **搜索热度**：关键词在搜索引擎的相对热度档位（高/中/低/长尾极低），依据工具知名度+词属性评估，供写作优先级参考，**非精确搜索量**；后续可从百度指数/5118 导出真实搜索量替换
- 由 `scripts/build_enhanced_kw.py` 从原始词库一键生成（词库更新后重跑一次即可）

## 快速开始

```bash
python <技能>/scripts/plan_daily.py
```

运行后输出当天规划（天数自动递增），按指纹去重记录写入 `.ai_seo_state.json`。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| `--kw` | 增强词库 CSV（默认 `assets/data/ai_enhanced_kw.csv`） |
| `--state` | 状态 JSON（记录已用指纹，跨日去重） |
| `--day N` | 手动指定第几天 |
| `--total N` | 每日关键词总数（默认 30） |
| `--reset` | 清空去重历史，从第 1 天开始 |
| `--out PATH` | 导出规划 md 文件 |

## 输出格式

```
AI SEO 关键词每日规划 · 第 N 天（周二）
词量：30（核心3/长尾12/支撑15）· 四维指纹去重
## 核心层
| # | 今日关键词 | 分类 | 题材 | 工具 | 意图 | 对象 | 指纹 | 内容策略 | 热度 | 推荐分 |
## 长尾层
## 支撑层
```

## 资源

### scripts/
- `plan_daily.py` — 主脚本：读增强词库 → 四维指纹去重 → 周排期 → 分层选词 → 输出带标签清单
- `build_enhanced_kw.py` — 从原始词库生成增强词库（词库更新后重跑）
- `update_check.py` — 版本更新检查 / 一键更新

### assets/
- `data/ai_enhanced_kw.csv` — 增强词库（1284 词，已清洗，唯一数据源）
- `data/ai_final_kw.csv` — 原始词库（1425 词，含搜索热度档位+热度分，作为 build_enhanced_kw 的输入）
