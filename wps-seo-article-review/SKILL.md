# WPS 国内 SEO 文章审查

## 概述

对 wps.cn 的国内 SEO 图文文章做**发布前合规与质量审查**，判定"可发布 / 需修改后再发布"，并给出逐项依据与修改建议。审查依据《国内-SEO审核要点》，覆盖五层：内容质量、规范硬性要求、广告法合规、品牌信息准确性、公众号宣推走查。

## 输入：待审文章

用户提供以下任一形式：

- **全文**：Markdown 或 HTML 正文（含标题、正文、配图 alt、FAQ、标签）
- **链接/草稿 ID**：wps.cn CMS 草稿链接或文号，需要时可让用户粘贴正文
- **本地文件路径**：如 `output/第3周/xxx/index.html` 或 `article.md`

## 工作流（第 0 步自动更新检查 + 5 步审查）

### 第 0 步：自动更新检查（每次调用先执行）

```bash
python scripts/update_check.py
```

- 有 24h 本地缓存；输出"发现新版本 vX.Y.Z"时先向用户提示并征询是否更新，同意后 `python scripts/update_check.py --update`
- 输出"已是最新"或"远程不可达"时静默继续

### 第 1 步：通读全文并提取审查要素

通读待审文章，提取：标题、目标关键词、正文各段、配图（含 alt）、FAQ 条目、标签、口吻、字数。若用户给的是链接，先请用户提供正文全文后再审查（审查必须基于完整原文）。

### 第 2 步：逐层审查

**第一层 · 内容质量（SEO 基础要点）**

按 [references/seo-basics.md](references/seo-basics.md) 逐条核对：

- **内容层面**：绝对化宣传语、虚构信息（价格/优惠/参数一律以官方会员页为准）、夹带私货（植入与 WPS 无关品牌）、诱导非官方下载（必须指向官网/应用商店）、大段抄袭资源池原文（须用自己的话重写并注明来源）
- **质量层面（AI 味重灾区）**：模板化开头（"随着科技的飞速发展"等）、空泛套话（赋能/抓手/闭环/颗粒度/一站式等黑话）、三段式万能标题（"XX，YY，ZZ"）、注水凑字数、通篇无人称说明书腔（多用"你"直接对话读者）
- **结构/配图层面**：AI 示意图配图（一律真实产品截图）、图片 alt 不含关键词

**第二层 · 规范硬性要求**

对照 [references/style-guide.md](references/style-guide.md) 中的规范表逐项核对：

| 项目 | 规范 |
| --- | --- |
| 篇幅 | 500–2000 字；教程/对比类偏长，问答/品牌类 500–1000 |
| 口吻 | 官方但不说教，客观克制，不贬低竞品 |
| 产品名 | 用官方全称：WPS Office、WPS 文字、WPS 表格、WPS 演示、WPS PDF、WPS AI、在线文档（WPS 365） |
| 标题 | frontmatter 管理，含目标关键词，15–30 字，可带数字/痛点/场景 |
| 结构件 | 封面图 → 图文段落（每关键段配图）→ FAQ（3–5 条）→ 智能标签（3–5 个） |
| FAQ | 每条 60–120 字，先给结论再给依据，不用"可能/或许"，抓取友好 |
| 发布 | 只存草稿箱，绝不发布（发布由用户手动完成） |

**第三层 · 广告法合规（最高风险层）**

按 [references/advertising-law.md](references/advertising-law.md) 逐条核对，重点红线：

1. 先判断是否构成广告（同一页面出现产品名+购买入口/二维码/联系方式通常算广告）
2. **绝对化用语**：国家级/最高级/最佳/最好/第一/唯一/首个/全网最低/遥遥领先等禁用及近似表述；例外须能证明真实
3. 数据/排名/评测可追溯：出处必须标明（机构名/题名/路径），适用范围/有效期/实验室条件写清楚，禁止虚构、断章取义、过期数据、AI 生成数据当权威背书
4. 竞品对比：允许比、不许踩（不点名、不出 Logo、不写"贵在广告费""抄袭""难用坑人"；对比维度/基准/时间/样本/数据来源写全）
5. 宣传真实全面不误导：不夸大 AI 能力（"100%准确""完全替代人工"）、不虚构排名/热销/好评、不隐瞒付费条件/有效期、不标题党与正文不符
6. 带转化内容必须能被认出是广告（需显著标明"广告"）
7. 搜索投放红线：不得把他人商标/企业名设为搜索关键词
8. 广告主对全部内容真实性负责，举不出证据按违法处理

**第四层 · 品牌信息准确性**

按 [references/brand-info.md](references/brand-info.md) 核对：

- 产品描述是否准确（会员体系：注册用户 / WPS超级会员 / WPS大会员；价格以官方会员页 `https://vip.wps.cn/home` 为准）
- 会员体系、产品全称、最新品牌资讯表述是否与官方一致、是否过时

**第五层 · 公众号宣推走查（适用于公众号推文）**

按 [references/wechat-walkthrough.md](references/wechat-walkthrough.md) 走查：内容（病句/产品描述准确/法规合规/敏感：擦边·新闻时政·员工关系）、标点（"方向、全半角）、图片（文案准确、配图与正文匹配、样张脱敏、敏感）、敏感日期（推送避开 512/64/77/918/1213 等禁娱日）。

### 第 3 步：出具审查报告

输出结构化审查报告，固定字段：

```
审查结论：可发布 / 需修改后再发布（红线项：<列出违规项>）
```

逐层列出检查结果（Markdown 表格），每项含：

| 检查项 | 结论 | 问题定位 | 依据 | 修改建议 |
| --- | --- | --- | --- | --- |

- 结论：`通过` / `需修改` / `违规`
- 任一层存在"违规"，或"需修改"超过合理数量，整体结论为"需修改后再发布"
- 修改建议要具体可执行（给出改法示例），不泛泛而谈

### 第 4 步：交付

- 默认只给审查报告，不改正文
- 用户要求修改时：按建议逐条修改，输出修订版全文，并再次快速复核红线项
- 审查报告可另存为 `审查报告_<文章名>.md` 供留档

## 审查红线速记（最高优先级）

| 红线 | 对应层级 |
| --- | --- |
| 绝对化用语（最好/第一/唯一/最高级/遥遥领先等） | 广告法 |
| 虚构价格/优惠/功能参数 | 内容质量 + 广告法 |
| 大段抄袭资源池原文 | 内容质量 |
| AI 味重（模板开头/黑话/注水/说明书腔） | 内容质量 |
| AI 示意图配图 / alt 无关键词 | 内容质量 |
| 夸大 AI 能力（100%准确/完全替代人工） | 广告法 |
| 贬低竞品/商业诋毁/踩一捧一 | 广告法 |
| 诱导非官方下载 / 夹带无关品牌 | 内容质量 |
| 标题党与正文不符 / 引用无出处 | 广告法 |
| 敏感日期发布（512/64/77/918/1213 等） | 公众号走查 |
