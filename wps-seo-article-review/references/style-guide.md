# 规范（硬性要求）

来源：《国内-SEO审核要点》第 2 节。用于第二层「规范硬性要求」审查。

## 规范总表

| 项目 | 规范 |
| --- | --- |
| 篇幅 | 500–2000 字；教程/对比类偏长，问答/品牌类 500–1000 |
| 口吻 | 官方但不说教，客观克制，不贬低竞品 |
| 产品名 | 用官方全称：WPS Office、WPS 文字、WPS 表格、WPS 演示、WPS PDF、WPS AI、在线文档（WPS 365） |
| 标题 | frontmatter 管理，含目标关键词，15–30 字，可带数字/痛点/场景 |
| 结构件 | 封面图 → 图文段落（每关键段配图）→ FAQ（3–5 条）→ 智能标签（3–5 个） |
| FAQ | 每条 60–120 字，先给结论再给依据，不用"可能/或许"，抓取友好 |
| 发布 | 只存草稿箱，绝不发布，发布由你手动完成 |

## 审查要点

- 篇幅是否落在 500–2000 字区间（按文章类型判断合理长度）
- 口吻是否官方且不说教、客观克制、未贬低竞品
- 产品名是否使用官方全称，未用错误/缩写叫法（如"WPS"后省略产品名、"wpsoffice"等）
- 标题是否含目标关键词、15–30 字、非三段式万能并列结构
- 结构件是否齐全：封面图 → 图文（每关键段配图）→ FAQ（3–5 条）→ 智能标签（3–5 个）
- FAQ 每条 60–120 字、先结论后依据、无"可能/或许"等不确定措辞、抓取友好
- 是否存在诱导发布的动作（技能只生成草稿，不发布）
