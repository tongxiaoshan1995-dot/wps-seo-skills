# WPS SEO 组别关键词周度规划

## 概述

一键输出"当周该写哪些关键词"的规划表：10 个策略组别 × 每组 5 词 = 50 词/周，覆盖《WPS_SEO完整关键词库》全部 12166 词，关键词按价值从高到低排列，自动跨周去重（每次调用与上一次建议不重复）。

## 自动更新检查（每次调用本技能，先执行这一步）

```bash
python scripts/update_check.py
```

- 有 24h 本地缓存，未过期直接读缓存（几乎无感）；如需强制刷新可先删除本地缓存再运行
- 输出“发现新版本 vX.Y.Z”时：向用户提示新版本与更新摘要（CHANGELOG），征询后执行 `python scripts/update_check.py --update` 完成更新
- 输出“已是最新”或“远程不可达”时静默继续，不阻塞规划任务
- 版本仓库：`tongxiaoshan1995-dot/wps-seo-skills`（多技能统一仓库，本技能为子目录，SUBDIR 自动适配）

## 数据源

- 完整词库：`wps_final_kw.csv`（12166 词，含 一级分类 / 二级主题 / 搜索意图 / GEO机会值 / 第三方流量指数 / 百度统计PV）
- 脚本自动定位：当前/最近工作区 `Documents/lingxi-claw/*/wps_final_kw.csv`（按修改时间取最新）→ 找不到则用技能内置副本 `assets/data/wps_final_kw.csv`
- 若词库被用户更新，优先读最新工作区版本，无需改脚本

## 快速开始

```bash
python <技能>/scripts/plan_weekly.py
```

运行后输出第 N 周规划（周次自动递增），并把去重记录写入工作区 `.wps_seo_state.json`。

## 10 个策略组别（筛选规则）

| 策略组别 | 对应页面 | 词库筛选规则（一级分类 / 二级主题） |
| --- | --- | --- |
| 下载安装 | 下载落地页 | 一级分类 = 下载安装 |
| 价格购买 | 价格/会员页 | 一级分类 = 价格与会员 |
| 对比选择 | 竞品对比页 | 一级分类 = 竞品对比与选型 |
| 模板获取 | 模板聚合页 | 一级分类 = 模板业务 |
| 格式转换 | 转换工具页 | 一级分类 = 格式转换与文档处理 |
| 故障解决 | FAQ解决页 | 组件功能与教程 且 二级主题 = WPS用户问题/故障解决 |
| 教程操作 | 教程内容页 | 组件功能与教程 且 二级主题 ≠ WPS用户问题/故障解决 |
| 功能认知 | 功能科普页 | 一级分类 = 功能教程与知识 |
| AI认知 | AI专题页 | 一级分类 = AI办公 |
| 品牌直达 | 品牌落地页 | 一级分类 = 品牌与官方入口 |

每组关键词**从高到低**排列：按价值列优先级取第一非空值降序（GEO机会值 > 第三方流量指数 > 百度统计PV > 社媒热度值）。

## 去重与周次机制

- 每次调用取出的关键词写入状态文件 `~Documents/lingxi-claw/<工作区>/.wps_seo_state.json`
- 下次调用自动排除历史已用词，保证与上次建议不重复
- 周次自动递增（首次为第 1 周），代表"当前产出到第 N 周"
- 某组未用词用尽时自动轮转，从该组头部重新取词，并在输出中提示
- 手动指定周次：`--week 3`；清空历史重来：`--reset`

## 参数说明

| 参数 | 说明 |
| --- | --- |
| `--csv PATH` | 指定词库 CSV（默认自动定位） |
| `--state PATH` | 指定状态 JSON（默认自动定位到工作区） |
| `--week N` | 手动指定周次 |
| `--per-group N` | 每组关键词数（默认 5） |
| `--out PATH` | 导出规划文件（`.md` 或 `.xlsx`） |
| `--reset` | 清空去重历史，从第 1 周开始 |

## 示例

```bash
# 本周规划（自动周次递增）
python <技能>/scripts/plan_weekly.py

# 导出第 3 周规划为 Markdown 与 Excel
python <技能>/scripts/plan_weekly.py --week 3 --out /path/第3周规划.md
python <技能>/scripts/plan_weekly.py --week 3 --out /path/第3周规划.xlsx

# 指定词库与状态路径
python <技能>/scripts/plan_weekly.py --csv /path/wps_final_kw.csv --state /path/state.json
```
