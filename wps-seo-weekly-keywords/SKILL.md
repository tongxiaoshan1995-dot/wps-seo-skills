# WPS SEO 每日关键词规划

## 概述

一键输出"今天该写哪些关键词"的规划表：四类策略词（品牌词 / 竞品词 / 通用词 / 功能词）按既定配比每日挑取 30 词（可用参数在 20~30 间调整），关键词按「月均搜索量」从高到低排列，自动跨日去重（每次调用给出的关键词与历史已用词不重复），某类词用尽时自动轮转该组、沿列表继续往下排。

## 自动更新检查（每次调用本技能，先执行这一步）

```bash
python scripts/update_check.py
```

- 有 24h 本地缓存，未过期直接读缓存（几乎无感）；如需强制刷新可先删除本地缓存再运行
- 输出“发现新版本 vX.Y.Z”时：向用户提示新版本与更新摘要（CHANGELOG），征询后执行 `python scripts/update_check.py --update` 完成更新
- 输出“已是最新”或“远程不可达”时静默继续，不阻塞规划任务
- 版本仓库：`tongxiaoshan1995-dot/wps-seo-skills`（多技能统一仓库，本技能为子目录，SUBDIR 自动适配）

## 数据源

- 首选最新关键词 Excel：`SEO关键词*.xlsx`（自动定位：当前/最近工作区 → 下载目录，按修改时间取最新；内含「wps品牌词 / 竞品词 / 通用词 / 功能词」四个 sheet，多列块结构脚本自动展平）
- 找不到 Excel 时使用技能内置统一副本 `assets/data/wps_daily_kw.csv`（1838 词，含 类别 / 关键词 / 月均搜索量 / 特色 / 竞争激烈程度）
- 若词库被用户更新（新 Excel 放工作区或下载目录），自动优先读最新版本，无需改脚本

## 快速开始

```bash
python <技能>/scripts/plan_daily.py
```

运行后输出第 N 天规划（天数自动递增），并把按组去重记录写入工作区 `.wps_seo_state.json`。

## 每日配比（可在脚本 RATIO 常量调整，务必合计 100%）

| 策略组别 | 配比 | 对应 sheet | 搜索意图 |
| --- | --- | --- | --- |
| 品牌词 | 35% | wps品牌词 | 品牌/官网/正版入口，路径短、转化快，重承接与信任，承接品牌直达流量 |
| 竞品词 | 10% | 竞品词 | 竞品/对比/替代需求，适合客观对比页与FAQ，拦截竞品搜索流量 |
| 通用词 | 15% | 通用词 | 办公软件泛需求，适合知识科普与工具页，拓展新用户认知 |
| 功能词 | 40% | 功能词 | word/excel/ppt等具体功能需求，意图精准，适合功能教程页与工具页 |

- 配比按「最大余数法」取整，保证每日词数严格等于总数（如 30 词 → 品牌 11 / 竞品 3 / 通用 4 / 功能 12；20 词 → 品牌 7 / 竞品 2 / 通用 3 / 功能 8）
- 每组关键词**从高到低**排列：按「月均搜索量」降序取词（频率越高的词越优先）

## 去重与天数机制

- 每次调用取出的关键词写入状态文件 `~Documents/lingxi-claw/<工作区>/.wps_seo_state.json`，**按策略组分别记录已用词**
- 下次调用自动排除本组历史已用词，保证每次输出的关键词与之前不重复
- 天数自动递增（首次为第 1 天），代表"当前产出到第 N 天"
- 某组未用词用尽时**自动轮转该组**：重置该组历史并从头继续往下取，同时在输出中提示（示例：通用词池仅 44 个，30 词档约 11 天轮转一次）
- 手动指定天数：`--day 3`；清空历史重来：`--reset`

## 参数说明

| 参数 | 说明 |
| --- | --- |
| `--xlsx PATH` | 指定关键词 Excel（默认自动定位最新 SEO关键词*.xlsx） |
| `--csv PATH` | 指定统一词库 CSV（优先级低于 --xlsx） |
| `--state PATH` | 指定状态 JSON（默认自动定位到工作区） |
| `--day N` | 手动指定第几天 |
| `--total N` | 每日关键词总数（默认 30，范围 20~30） |
| `--out PATH` | 导出规划文件（`.md` 或 `.xlsx`） |
| `--reset` | 清空去重历史，从第 1 天开始 |

## 示例

```bash
# 今日规划（天数自动递增）
python <技能>/scripts/plan_daily.py

# 每日 20 词（品牌7/竞品2/通用3/功能8）
python <技能>/scripts/plan_daily.py --total 20

# 导出第 3 天规划为 Markdown 与 Excel
python <技能>/scripts/plan_daily.py --day 3 --out /path/第3天规划.md
python <技能>/scripts/plan_daily.py --day 3 --out /path/第3天规划.xlsx

# 指定最新关键词 Excel / 统一词库与状态路径
python <技能>/scripts/plan_daily.py --xlsx /path/SEO关键词0828.xlsx
python <技能>/scripts/plan_daily.py --csv /path/wps_daily_kw.csv --state /path/state.json
```
