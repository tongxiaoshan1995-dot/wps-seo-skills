# WPS SEO 每日关键词规划 v3

## 概述

一键输出"今天该写哪些关键词"的规划表：按**分层推荐**（核心 3 / 长尾 12 / 支撑 15）每日挑取 30 词（可用 `--total` 调整），核心层吃排名、长尾层吃细分长尾、支撑层铺量+内链承接。关键词按**三维指纹**去重，保证：
- **当天 30 词指纹全唯一**（题材×意图×操作对象）
- **跨日不重复**（已用指纹持久化，全站同指纹只出现一次）
- **周一至周五题材/意图差异化**（题材轮转，不扎堆）
- **已剔除会员/价格词**（题材与内容层均不产出）

## 周一到周五差异化排期

| 日期 | 主打题材 | 主攻意图 | 定位 |
|------|---------|---------|------|
| 周一 | Excel + Word | 教程操作 + 故障解决 | 基础文档处理，教程为主 |
| 周二 | PDF + PPT | 模板获取 + 教程操作 | 格式转换+模板制作 |
| 周三 | WPS AI + 云文档/在线 | AI认知 + 教程操作 | AI能力+在线协作新卖点 |
| 周四 | 下载/安装 + WPS综合 | 下载安装 + 功能认知 | 转化层，承接下载安装 |
| 周五 | Office通用 + WPS综合 | 对比选型 + 功能认知 | 决策对比，周结尾收口 |

第 6 天自动回到周一（周一~周五循环）。

## 分层推荐（每天 30 篇）

| 层 | 篇数 | 定位 | 选词逻辑 |
|----|------|------|---------|
| 核心 | 3 | 深度写、吃排名、配图 | 主打题材×主攻意图的高分指纹 |
| 长尾 | 12 | 吃细分长尾 | 指纹去重 + 题材分散 |
| 支撑 | 15 | 铺量 + 内链承接 | 指纹去重 + 题材分散（补充铺量） |

## 三维指纹去重

每个词打 3 个标签：**题材 × 意图 × 操作对象**，组成唯一指纹。例如：
- `Excel·教程操作·合并单元格`（excel表格合并单元格）
- `PDF·故障解决·打不开`（pdf文件打不开）
- `WPS AI·AI认知·通用`（能做ppt的ai）

同一指纹全站只推荐 1 次（状态文件 `.wps_seo_state.json` 按指纹持久化，跨日去重）。

## 内容策略标签

每词带一个内容策略标签，供写文章技能选写作模板：
- **高关联(整篇WPS)**：品牌/价格/下载词，整篇围绕 WPS
- **中关联(通用+WPS章节)**：教程/故障/模板/认知词，先讲通用方法再带出 WPS
- **低关联(方法论轻带)**：纯方法论词，末尾轻提 WPS

## 数据源

- 增强词库 `assets/data/wps_enhanced_kw.csv`（11376 词，已清洗分类：题材/意图/操作对象/指纹/内容策略/搜索量/题材分，已剔除会员/价格词）
- 由 `scripts/build_enhanced_kw.py` 从原始词库 `wps_final_kw.csv` 一键生成（词库更新后重跑一次即可）

## 快速开始

```bash
python <技能>/scripts/plan_daily.py
```

运行后输出第 N 天规划（天数自动递增），按指纹去重记录写入 `.wps_seo_state.json`。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| `--kw` | 增强词库 CSV（默认 `assets/data/wps_enhanced_kw.csv`） |
| `--state` | 状态 JSON（记录已用指纹，跨日去重） |
| `--day N` | 手动指定第几天 |
| `--total N` | 每日关键词总数（默认 30） |
| `--reset` | 清空去重历史，从第 1 天开始 |
| `--out PATH` | 导出规划 md 文件 |

## 输出格式

```
WPS SEO 关键词每日规划 v3 · 第 N 天（周一）
词量：30（核心3/长尾12/支撑15）· 三维指纹去重 · 已去会员/价格
## 核心层
| # | 今日关键词 | 题材 | 意图 | 对象 | 指纹 | 内容策略 | 搜索量 | 推荐分 |
## 长尾层
## 支撑层
```

## 资源

### scripts/
- `plan_daily.py` — 主脚本：读增强词库 → 三维指纹去重 → 周排期 → 分层选词 → 输出带标签清单
- `build_enhanced_kw.py` — 从原始词库生成增强词库（词库更新后重跑）
- `update_check.py` — 版本更新检查 / 一键更新

### assets/
- `data/wps_enhanced_kw.csv` — 增强词库（11376 词，已清洗，唯一数据源）
- `data/wps_final_kw.csv` — 原始词库（12166 词，作为 build_enhanced_kw 的输入）
- `data/theme_score.json` — 题材热度分
