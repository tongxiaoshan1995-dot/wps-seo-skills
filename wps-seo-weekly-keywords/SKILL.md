# WPS SEO 每日关键词规划

## 概述

一键输出"今天该写哪些关键词"的规划表：四类策略词（品牌词 / 竞品词 / 通用词 / 功能词）按既定配比每日挑取 30 词（可用参数在 20~30 间调整），关键词按**多信号推荐分**从高到低排列，自动跨日去重（每次调用给出的关键词与历史已用词不重复），某类词用尽时自动轮转该组、沿列表继续往下排。

推荐分公式：

```
推荐分 = 搜索量×0.5 + 题材热度×0.3 + SEM×0.2 − 已覆盖惩罚
```

- **搜索量**：取月均搜索量或百度统计PV（组内 log 归一化）
- **题材热度**：CMS 文章篇均阅读量按题材映射归一化（`assets/data/theme_score.json`，可 `--theme` 覆盖为最新月度数据）
- **SEM**：命中 `--sem` 词表的词得满分（未提供词表时该 20% 权重空置，不影响出词）
- **已覆盖惩罚**：关键词出现在已发布文章标题中（≥4 字子串匹配）→ 直接剔除（`--covered` 指定标题文件，或自动拉取 CMS 8 月已发布文章）

## 自动更新检查（每次调用本技能，先执行这一步）

```bash
python scripts/update_check.py
```

- 有 24h 本地缓存，未过期直接读缓存（几乎无感）；如需强制刷新可先删除本地缓存再运行
- 输出“发现新版本 vX.Y.Z”时：向用户提示新版本与更新摘要（CHANGELOG），征询后执行 `python scripts/update_check.py --update` 完成更新
- 输出“已是最新”或“远程不可达”时静默继续，不阻塞规划任务
- 版本仓库：`tongxiaoshan1995-dot/wps-seo-skills`（多技能统一仓库，本技能为子目录，SUBDIR 自动适配）

## 数据源

- 完整词库 `assets/data/wps_final_kw.csv`（12166 词，含 一级分类 / 二级主题 / 百度统计PV / 第三方流量指数 / GEO机会值 / 社媒热度值 / 搜索意图 / 需求级别 / 数据来源）
- 合并 `assets/data/wps_daily_kw.csv`（1838 词，含 月均搜索量 / 特色 / 竞争激烈程度；daily 独有词整条补充进候选池，尤其竞品词如 千问/豆包 等真实搜索量在 daily）
- 题材热度 `assets/data/theme_score.json`（CMS 文章篇均阅读量按题材映射归一化；可按月更新）
- 也支持 `--final-kw` / `--daily-csv` / `--xlsx` 指定最新 Excel（自动定位：当前/最近工作区 → 下载目录，按修改时间取最新）

## 快速开始

```bash
python <技能>/scripts/plan_daily.py
```

## 每日配比（可在脚本 RATIO 常量调整，务必合计 100%）

| 策略组别 | 配比 | 对应词库一级分类 | 搜索意图 |
| --- | --- | --- | --- |
| 品牌词 | 35% | 品牌与官方入口 / 下载安装 | 品牌/官网/正版入口，路径短、转化快，重承接与信任，承接品牌直达流量 |
| 竞品词 | 10% | 竞品对比与选型 | 竞品/对比/替代需求，适合客观对比页与FAQ，拦截竞品搜索流量 |
| 通用词 | 15% | 内容与社媒词 / 协同办公与企业 / 其他 / 云文档与在线办公 / 价格与会员 | 办公软件泛需求，适合知识科普与工具页，拓展新用户认知 |
| 功能词 | 40% | 组件功能与教程 / 功能教程与知识 / 格式转换与文档处理 / 模板业务 / AI办公 | word/excel/ppt等具体功能需求，意图精准，适合功能教程页与工具页 |

- 配比按「最大余数法」取整，保证每日词数严格等于总数（如 30 词 → 品牌 11 / 竞品 3 / 通用 4 / 功能 12；20 词 → 品牌 7 / 竞品 2 / 通用 3 / 功能 8）
- **功能词题材多样性**：Excel / PPT / word / PDF / WPS教程 / 在线文档 / office / WPS AI 各保底 1 词（取该题材推荐分最高者），剩余名额按推荐分从全部候选补充，避免单一题材霸榜（NAV 导航下载类不保底，仅按分自然参与）

## 去重与天数机制

- 每次调用取出的关键词写入状态文件 `<技能>/.wps_seo_state.json`，**按策略组分别记录已用词**
- 下次调用自动排除本组历史已用词，保证每次输出的关键词与之前不重复
- 天数自动递增（首次为第 1 天），代表"当前产出到第 N 天"
- 某组未用词用尽时**自动轮转该组**：重置该组历史并从头继续往下取，同时在输出中提示
- 手动指定天数：`--day 3`；清空历史重来：`--reset`

## 参数说明

| 参数 | 说明 |
| --- | --- |
| `--final-kw PATH` | 完整词库 CSV（默认技能内置 `assets/data/wps_final_kw.csv`） |
| `--daily-csv PATH` | daily 词库 CSV（默认技能内置 `assets/data/wps_daily_kw.csv`） |
| `--xlsx PATH` | 关键词 Excel（指定时优先于内置 CSV；未指定自动定位最新 SEO关键词*.xlsx） |
| `--theme PATH` | 题材热度 JSON（默认技能内置 `assets/data/theme_score.json`） |
| `--sem PATH` | SEM 词表 CSV/TXT（每行一个词或 CSV 第一列；命中该词加权 20%） |
| `--covered PATH` | 已覆盖标题文件（每行一个文章标题；未指定自动拉取 CMS 8 月已发布文章标题剔除已写词） |
| `--state PATH` | 指定状态 JSON（默认 `<技能>/.wps_seo_state.json`） |
| `--day N` | 手动指定第几天 |
| `--total N` | 每日关键词总数（默认 30，范围 20~30） |
| `--out PATH` | 导出规划文件（`.md` 或 `.xlsx`） |
| `--reset` | 清空去重历史，从第 1 天开始 |

## 示例

```bash
# 今日规划（天数自动递增）
python <技能>/scripts/plan_daily.py

# 每日 20 词（品牌7/竞品2/通用3/功能8）
python <技能>/scripts/plan_daily.py --total 20

# 启用 SEM 信号（本月投放词组加权）
python <技能>/scripts/plan_daily.py --sem /path/sem_words.csv

# 指定已覆盖标题文件 + 导出规划
python <技能>/scripts/plan_daily.py --covered /path/covered_titles.txt --out /path/第3天规划.md

# 指定最新关键词 Excel / 状态路径
python <技能>/scripts/plan_daily.py --xlsx /path/SEO关键词0828.xlsx --state /path/state.json
```
