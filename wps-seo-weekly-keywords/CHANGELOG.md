# CHANGELOG

本文记录 wps-seo-weekly-keywords 技能的版本变更。每次发布前递增 `VERSION` 并在此追加记录，供订阅者查看更新内容。

## 2.0.0 (2026-08-31)

**重构**：由「周度 10 组别规划」改为「每日四类策略词规划」。
- 数据源切换为最新《SEO关键词0828.xlsx》四类词表（品牌词 522 / 竞品词 259 / 通用词 44 / 功能词 1016，合并去重 1838 词），自动定位工作区/下载目录最新 Excel，缺省用内置副本 `wps_daily_kw.csv` 兜底
- 每日配比：品牌词 35% / 竞品词 10% / 通用词 15% / 功能词 40%（合计 100%，最大余数法精确取整），每日 20~30 词（默认 30，`--total` 可调）
- 排序规则：每组按「月均搜索量」从高到低提炼价值最高的关键词
- 去重机制：按策略组分别持久化已用词，跨日不重复；某组用尽自动轮转该组、沿列表继续往下排（通用词池小，30 词档约 11 天轮转一次）
- 脚本：新增 `scripts/plan_daily.py`（替代 `plan_weekly.py`），输出「策略组别 / 今日关键词 / 搜索意图」四列表

## 1.1.4 (2026-08-28)

**文档修正**：SKILL.md 第 0 步更新检查命令由 `--force` 改为无参运行（脚本无该参数），并补充强制刷新说明。

## 1.1.1 (2026-08-28)

**修复**：更新检测改用 git 权威通道（`git ls-remote` 对比 HEAD），绕开 CDN 缓存延迟漏检；首次运行也对比 VERSION。

## 1.1.3 (2026-08-28)

**修复**：--update 覆盖改用系统命令（robocopy/cp），临时目录清理兼容沙箱限制，避免 Python 删除被拦截导致更新失败。

## 1.1.0 (2026-08-28)

**机制增强**：加入“自动更新提醒”——每次调用本技能先执行 `update_check.py --force`，GitHub 有新版本时向用户提示并支持一键更新。
- SKILL.md 新增「自动更新检查」章节
- 版本仓库统一为多技能仓库 `tongxiaoshan1995-dot/wps-seo-skills`

## 1.0.0 (2026-08-27)

首次正式发布，纳入 `wps-seo-skills` 多技能版本仓库，接入 `update_check.py` 更新机制。

**功能**：为 wps.cn 生成 WPS SEO 组别关键词周度规划。读取《WPS_SEO完整关键词库》（12166 词），按 10 个策略组别（下载安装/价格购买/对比选择/模板获取/格式转换/故障解决/教程操作/功能认知/AI认知/品牌直达）每组挑取价值最高的关键词，输出「策略组别 / 本周关键词 / 搜索意图」三列表，关键词从高到低排列，且每次调用与上次建议不重复（自动持久化去重）。

**脚本**：`scripts/plan_weekly.py`。
