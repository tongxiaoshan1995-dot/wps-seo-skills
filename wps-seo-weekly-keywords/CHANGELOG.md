# CHANGELOG

本文记录 wps-seo-weekly-keywords 技能的版本变更。每次发布前递增 `VERSION` 并在此追加记录，供订阅者查看更新内容。

## 3.0.0 (2026-09-02)

**算法升级**：由「月均搜索量单一排序」改为「多信号加权推荐」。
- 数据源升级：改用完整词库 `wps_final_kw.csv`（12166 词，含百度PV/流量指数/GEO机会值/社媒热度/需求级别/搜索意图/二级主题），并合并 `wps_daily_kw.csv` 月均搜索量（daily 独有词整条补充进候选池，尤其竞品词）；内置 `assets/data/theme_score.json` 题材热度分
- 推荐分公式：`搜索量×0.5 + 题材热度×0.3 + SEM×0.2 − 已覆盖惩罚`（搜索量取月均搜索量或百度PV，组内归一化；题材热度按 CMS 文章篇均阅读量映射；SEM 命中 `--sem` 词表得满分；已覆盖词直接剔除）
- 题材热度闭环：按 8 月 CMS 文章篇均阅读量生成题材分（PPT 1.0 / office 0.86 / WPS教程 0.81 / 在线文档 0.44 / word 0.42 / Excel 0.27 / PDF 0.22 / WPS AI 0.0），推荐方向与内容验证对齐，可 `--theme` 覆盖
- 功能词题材多样性：Excel/PPT/word/PDF/WPS教程/在线文档/office/WPS AI 各保底 1 词（保底名额），剩余按推荐分补充，避免单一题材霸榜
- 数据清洗：脏词正则过滤（含 \ / . ' 引号 URL 等）、垃圾/截断词过滤（wps官/泛站/已屏蔽等）、竞品词要求含对比/选型语义（自家品牌词需含竞品名，避免 wvs网页版入口 等噪音）
- 已覆盖剔除：关键词出现在已发布文章标题中（≥4字子串匹配）直接剔除，支持 `--covered` 指定标题文件或自动拉取 CMS
- SEM 权重空置时可正常出词（20% 权重暂时不参与），提供 SEM 词表后自动启用

## 2.0.0 (2026-08-31)

**重构**：由「周度 10 组别规划」改为「每日四类策略词规划」。
- 数据源切换为最新《SEO关键词0828.xlsx》四类词表（品牌词 522 / 竞品词 259 / 通用词 44 / 功能词 1016，合并去重 1838 词），自动定位工作区/下载目录最新 Excel，缺省用内置副本 `wps_daily_kw.csv` 兜底
- 每日配比：品牌词 35% / 竞品词 10% / 通用词 15% / 功能词 40%（合计 100%，最大余数法精确取整），每日 20~30 词（默认 30，`--total` 可调）
- 排序规则：每组按「月均搜索量」从高到低提炼价值最高的关键词
- 去重机制：按策略组分别持久化已用词，跨日不重复；某组用尽自动轮转该组、沿列表继续往下排（通用词池小，30 词档约 11 天轮转一次）
- 脚本：新增 `scripts/plan_daily.py`（替代 `plan_weekly.py`），输出「策略组别 / 今日关键词 / 搜索意图」四列表

## 1.0.0 (2026-08-27)

首次正式发布，纳入 `wps-seo-skills` 多技能版本仓库，接入 `update_check.py` 更新机制。

**功能**：为 wps.cn 生成 WPS SEO 组别关键词周度规划。读取《WPS_SEO完整关键词库》（12166 词），按 10 个策略组别（下载安装/价格购买/对比选择/模板获取/格式转换/故障解决/教程操作/功能认知/AI认知/品牌直达）每组挑取价值最高的关键词，输出「策略组别 / 本周关键词 / 搜索意图」三列表，关键词从高到低排列，且每次调用与上次建议不重复（自动持久化去重）。

**脚本**：`scripts/plan_weekly.py`。
